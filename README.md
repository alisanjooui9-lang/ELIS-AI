# ELIS AI

## 🤖 هوش مصنوعی ELIS

ELIS AI یکی از پروژه‌های **ELIS Studio** است؛
یک دستیار هوشمند فارسی که با هدف پاسخ‌گویی، آموزش، حل مسئله، تحقیق و انجام وظایف مختلف ساخته می‌شود.
